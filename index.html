Learning Goals

This self-contained worksheet is for electronics, maintenance and procurement learners practising evidence review. Estimated study time: about twenty minutes. It does not teach installation, soldering, battery-pack repair or flight approval.

  • Separate a part's sourcing description from its documented fit and condition.
  • Identify missing exact-model, position, connector and board-revision evidence.
  • Write a sourcing request that keeps confirmed facts and unresolved questions separate.

Enterprise Spare-Parts Evidence Worksheet

Updated 3 October 2026. Use this worksheet when comparing a replacement module with an existing aircraft or preparing a parts request. It organizes the evidence needed for a compatibility decision; it does not certify fit, airworthiness or a successful repair.

OEM-pulled describes the sourcing and condition route. It does not mean brand-new, manufacturer-authorized or universally interchangeable. A shared family name or a similar photograph is not enough to match a board, cable, shell or power module.

Worked Example: A Matrice 30 Battery Port Board

A listing titled DJI Matrice 30 Battery Port Board Module — OEM-pulled identifies a battery-interface module. It does not prove compatibility with a different aircraft or board revision. Compare the removed module with the supplied-item evidence, confirm the connector and board version, and make the package scope explicit. This example identifies a current catalogue route; it does not assert that we tested a particular customer's aircraft. Stock, prices and written terms must be checked at order time.

Prepare a Useful Request

Include the exact model, module position, readable markings, connector photos, required quantity and the unresolved question. Keep private aircraft identifiers and customer information out of public posts. Agree any inspection, testing, documentation and packing scope before procurement begins.

Practise the Evidence Decision

The following cases are hypothetical classroom exercises. They are not customer records, actual component tests or manufacturer findings.

Case A: A Family Name Is Not a Part Match

A buyer requests a battery-interface board for a Matrice-series aircraft. The supplier's title names a Matrice 30 module, but the buyer has supplied only the family name. There are no readable board markings or connector photographs from the removed item.

  1. Which identities are confirmed, and which remain unknown?
  2. What evidence would you request before treating the item as a replacement candidate?
  3. Would a lower price resolve the missing compatibility evidence? Explain.

Case B: Provenance and Fit Answer Different Questions

A listing describes a part as OEM-pulled and provides clear photographs. The component's side and board revision are not stated. A learner concludes that the label guarantees it is new and will fit any aircraft from the same family.

  1. Identify both unsupported conclusions.
  2. Rewrite the conclusion using only the stated evidence.
  3. List the questions that remain before an order or installation decision.

Sample Answers

Case A: the offered listing identifies a Matrice 30 module; the buyer's exact aircraft variant and removed component remain unconfirmed. Ask for the exact aircraft identity, component position, readable part/board markings and connector/mounting evidence. Record any required revision, pairing or calibration question as unresolved until an appropriate source or qualified review addresses it. Price does not establish fit.

Case B: OEM-pulled describes a sourcing route; it does not establish brand-new condition or universal compatibility. A bounded conclusion is: the supplier describes this item as OEM-pulled and provides photographs, while its side, revision, exact-model match and check scope remain unknown. Request those missing facts and confirm the supplied-item condition and included pieces in writing. No installation or flight suitability is inferred.

Write Your Own Request

Use the format: exact aircraft/variant; component position; readable identifiers; required quantity; available evidence; unresolved compatibility questions; agreed check scope; included pieces; handover point. Avoid personal or customer identifiers in a public classroom example. Compare the result against all eight worksheet rows above.
